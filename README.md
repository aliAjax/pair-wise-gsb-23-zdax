# hxwl-09 半导体洁净室巡检调度台

夜班巡检调度台：巡检任务、充电位与仪器借用联动，替代人工排班。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109

## 功能

### 任务-充电位-仪器联动
- 机器人电量低于 40% 自动申请充电；充电位容量满后机器人排队等位，任务先排队、不能下发
- 派发任务时同时占用机器人与仪器，仪器借出互斥（机器人与复检员不能同时抢一台）
- 仪器校准确认一变，未开始（待派发/排队/已下发未开始）的任务立即失效，并按可用仪器自动生成新一代重排任务；进行中任务不受影响

### 断网容错
- 基站断网时任务进度留在本地暂存（outbox），恢复联网后自动合并现场记录
- 现场记录带幂等编号，重复回传只入账一次
- 仪器号与任务号对不上时，系统版与现场版两版都留，任务阻断，班长选完才能继续

### 权限
- 巡检员：派发/开始/回传/完成任务；越权占用充电位会被拒绝并记入审计
- 班长：占用/释放充电位、变更校准确认、裁决版本冲突
- 审计员：只读，任何写操作都会被拒绝并记入审计

### 辅助
- 「推进 15 分钟」模拟电量消耗与充电补位
- 「模拟现场回传」一次生成正常、重复、错号三类记录，便于验证合并逻辑
- 全量操作审计日志
